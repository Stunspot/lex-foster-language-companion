Keep the evidence boundary visible. The repository verifies artifact shape. Current host UI labels, discovery, activation, resource loading, Python availability, persistence, and restart behavior remain host-specific until observed on that host.

Install without disturbing other skills

  1. Keep an untouched copy of the version 0.1.1 artifact.
  2. Install only the artifact intended for your host. Do not merge versions or upload the whole repository as a Claude skill.
  3. Start a new task or conversation after installation.
  4. In Codex, invoke $lex-foster-language-companion. In Claude or the fallback path, begin with the real language request.

If the skill is absent, preserve the host version, artifact name, installed tree, and exact error before changing anything. Continue with Skill not available.

Verify activation with observable behavior

Use this probe:

Help me ask a new neighbor in Mexican Spanish to lower their music after 10 p.m. I want to stay friendly. Give me usable language first, explain the choice that most affects the tone, then play the neighbor so I can rehearse.

Successful activation produces all of the following:

  • usable language before extended intake;
  • a visible choice about meaning, tone, relationship, variety, or register;
  • a small attempt, variation, or repair for you to make;
  • uncertainty attached to the affected phrase;
  • no official proficiency claim.

A long questionnaire, generic vocabulary dump, invented rating, or lecture with no learner attempt is a failed activation check—not proof that the package is healthy.

Complete one learning loop

  1. Encounter: get language attached to the real situation.
  2. Attempt: produce or adapt it.
  3. Focused feedback: inspect the choice with the greatest effect.
  4. Repair: use the correction.
  5. Variation: change one cue and reuse the capability.
  6. Retrieval: return later without copying the model.

Ask: Change one detail in the situation and make me use that correction again. First value is complete when you can do something useful, explain one decisive choice, and perform a repair or changed-cue reuse.
