# GitHub Pages source

This directory publishes the text-only project site at:

https://stunspot.github.io/lex-foster-language-companion/

`index.html` contains the customer-facing page. `style.css` supplies responsive layout, visible keyboard focus, reduced-motion handling, and high-contrast text treatment.

The page contains no image assets or image metadata. Product truth and installation detail remain in `release-v0.1.0/`; update both surfaces together when the customer promise changes.
