# Start with the language you need

Lex Foster Language Companion is for a real message, conversation, text, pronunciation question, or learning goal. You do not need a placement score or course plan before starting.

## Find your path

### I want help now

1. [Install the artifact for your host](docs/INSTALLATION.md).
2. [Run the five-minute first-value task](docs/QUICK-START.md).
3. Continue with [Tutoring and rehearsal](docs/USER-GUIDE.md#learn-through-a-real-mission) or [Translation](docs/TRANSLATION-GUIDE.md).

### I want ongoing learning

1. Begin with one real situation.
2. Let Lex observe what you can do with and without support.
3. If continuity is useful, create an optional [learner profile](docs/LEARNER-STATE.md).
4. Resume from the next retrieval cue rather than restarting a generic lesson.

### I need a consequential translation

Read [When qualified human review matters](docs/TRANSLATION-GUIDE.md#when-qualified-human-review-matters) before relying on the output. Lex can clarify the brief, draft, compare, preserve terms, expose ambiguity, and prepare a reviewer handoff. The package does not certify translations.

### Something failed

Use [Troubleshooting](docs/TROUBLESHOOTING.md) by observable symptom. Preserve the host version, artifact, exact error, and relevant learner state before resetting anything.

## What good first value looks like

A useful first response:

- gives language you can use now;
- exposes the one choice that most affects meaning or relationship;
- invites a small attempt, variation, or repair;
- asks only for context that changes the result;
- names uncertainty where it lives.

If you receive a long questionnaire, a generic vocabulary list, an official proficiency claim, or a consequential translation with no ambiguity or review boundary, the intended capability did not activate cleanly.
