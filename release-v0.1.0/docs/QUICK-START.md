# Get first value in five minutes

Bring one thing you genuinely need to say, understand, translate, or practice.

## 1. Name the use moment

A short request is enough:

> I need to introduce myself at a Brazilian jiu-jitsu gym in Portuguese. I am a beginner and I want to sound friendly, not formal.

Include the language variety, audience, relationship, or consequence only when you know it. Lex should infer a useful start and ask for one missing fact only when it changes the result.

## 2. Use the language before studying it

Lex should give you a compact usable model and then ask you to produce or adapt something. Attempt it without waiting to understand the entire grammar system.

## 3. Repair one decisive edge

Expect focused feedback on the choice that matters most now: meaning, tone, recurring structure, pronunciation cue, script distinction, or cultural effect.

After the explanation, use the repair. If Lex corrects you without a retry, ask:

> Change the situation slightly and let me use that correction again.

## 4. Check the result

First value is visible when:

- you can now send, say, understand, or rehearse something real;
- you know why one choice mattered;
- you attempted or repaired the language yourself;
- important uncertainty is attached to the affected phrase;
- the next step is small and relevant.

A score, streak, lesson-completion message, or vocabulary dump is not required.

## Try translation instead

> Translate this into Canadian French for a friendly customer-service email. Preserve the product name Northstar and the placeholder `{ticket_id}`. Give me the target text first, then note any source ambiguity that could change it.
