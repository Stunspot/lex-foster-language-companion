## Evidence vocabulary

The documentation uses these states when the distinction changes what a reader may trust:

- `source-verified`: confirmed directly in the versioned repository or package;
- `reported`: recorded by a retained source but not independently rerun in the current review;
- `inferred`: a bounded conclusion from available evidence;
- `conflicted`: credible sources disagree;
- `not examined`: the surface was outside the review;
- `not tested`: the claim requires an execution or user test that did not run.

A fluent sentence, existing file, successful lint, or HTTP response does not silently promote another evidence state.
