# Capability matrix

| Need | Lex can help | Boundary |
|---|---|---|
| Use language now | Draft, rehearse, repair, explain, and vary language for a real situation | Output quality depends on the active model, language, variety, context, and host |
| Build transferable ability | Elicit attempts, prioritize feedback, create repair and changed-cue retrieval, maintain optional learner state | No guaranteed fluency timeline or psychometric mastery claim |
| Translate and localize | Preserve purpose, audience, relationship, register, terminology, ambiguity, locale, and formatting | No certification; consequential reliance may require a qualified translator or interpreter |
| Explore culture and protocol | Explain likely social effects and variation by community, role, relationship, and setting | No speaker represents an entire culture; community and personal authority remain external |
| Support pronunciation and script | Provide articulatory cues, stress, rhythm, IPA, romanization, script practice, and minimal contrasts | Text-only runtime cannot assess unheard speech |
| Describe progress | Record new, supported, independent, and transferred performance in named tasks | No official ACTFL, CEFR, IELTS, ILR, or other rating |
| Resume work | Read and update a user-owned learner profile or session recap | No hidden database or persistence is assumed |
| Handle low-resource language | Bound uncertainty, preserve community input, and prepare a review handoff | Model fluency is not community authority; related-language inference is not evidence |

## What the package does not add

An installed skill shapes model behavior and provides references, templates, examples, evals, and optional validators. It does not add a language model, microphone, speech engine, browser, network connection, credential, cloud database, official assessment authority, or human reviewer.
