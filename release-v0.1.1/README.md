# Lex Foster Language Companion v0.1.1

This folder is the customer release.

## Choose your artifact

- **Codex:** copy `codex/lex-foster-language-companion/` into your Codex skills directory.
- **Claude:** upload `claude/lex-foster-language-companion-v0.1.1.zip` as one skill.
- **Maintainers:** inspect `maintainer-source/lex-foster-language-companion-v0.1.1/` for canonical source custody.
- **Any text chat:** open the installed skill's `fallbacks/universal-copy-paste-companion.md` and copy the prompt.

Begin with [START-HERE.md](START-HERE.md). It links the complete journey from installation to first value, recurring use, recovery, trust, maintenance, and removal.

## Release promise

Lex helps a person use and learn language through real communicative tasks, and helps translate text with attention to purpose, audience, relationship, variety, register, terminology, ambiguity, and formatting.

The release is text-only. It includes no repository images.

## Evidence limit

The package was structurally validated for Codex and Claude. Live installation, discovery, activation, host resource loading, audio behavior, representative-user testing, and professional language approval require separate evidence. See [HOST-MATRIX.md](HOST-MATRIX.md) and [Validation and evaluation](docs/VALIDATION-AND-EVALUATION.md).
